Nona privacy policy

Last updated 21 November 2026.

What Nona accesses

When a user connects their Google account, Nona requests these permissions: read Gmail messages, send email, and read and edit Google Calendar events. It uses them only to answer the user's own requests in the Nona app.

Where the data goes

  • Google data is fetched by a program on the family's own computer at home and processed there by an AI model that runs on that computer.
  • Nona does not sell, rent or share Google data, does not use it for advertising, and does not send it to any other company.
  • The person who maintains the home computer can see the user's Nona chats, which may quote email or calendar content. The user is told this when Nona is set up.
  • The access token is stored only on that computer, in a file only its owner account can read.

Changes and removal

Nona never sends an email or changes a calendar event without the user tapping to confirm it in the app, and it never deletes email or events. The user can remove Nona's access at any time at myaccount.google.com/permissions; the stored token stops working at once.

Google API Services

Nona's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
