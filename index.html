Nona

Nona is a private iPhone assistant for one family. It runs on a computer at home: the phone app talks only to that computer, over the family's private network.

With the user's permission, Nona connects to the user's Google account so the assistant can:

  • search and read the user's Gmail messages,
  • send an email, only after the user taps Send on a card that shows the whole message,
  • read the user's Google Calendar, and add or move an event, only after the user taps to confirm.

Nona is not offered to the public and has no sign-up.
